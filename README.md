# Most Streamed Spotify Songs — 2023

An exploratory Python analysis of a 2023 Spotify songs dataset containing track popularity and audio-related attributes.

## Repository contents

- `spotify-2023.csv` — source dataset.
- `Most-Streamed-Spotify-Songs-2023.ipynb` — analysis notebook.
- `Most_Streamed_Spotify_Songs_2023.ipynb` — alternate notebook version retained from the original project.

This is an earlier exploratory portfolio project. More recent repositories on this profile use more formal project structures, requirements files and reproducibility documentation.
